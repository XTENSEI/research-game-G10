# assets/

Art, audio, fonts, sprites, and tilemaps.

- `sprites/` : Character sprites, NPC portraits, items
- `tilemaps/` : Biome tilemap data (Tiled JSON or similar)
- `audio/` : Music and SFX
- `fonts/` : Dialogue and UI fonts
- `particles/` : Particle sprite sheets (stars, magic, bubbles)
- `ui/` : Dialogue boxes, choice menus, HUD elements
